# Pollinations AI Agent

A professional FastAPI-based API and dashboard for Pollinations.ai's image/text/audio generation, powered by LangChain agents.

## Quick Start
- Deployed on Render: https://atlas-e7ck.onrender.com/
- Dashboard: https://atlas-e7ck.onrender.com/
- API Docs: https://atlas-e7ck.onrender.com/api-docs
- API Root: https://atlas-e7ck.onrender.com/api/

## Features
- Chat agent with tools for generation.
- GET/POST endpoints for image/text/audio.
- Professional Bootstrap UI.

## Local Run
```bash
pip install -r requirements.txt
uvicorn main:app --reload
