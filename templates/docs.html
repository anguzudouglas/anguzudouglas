API Documentation

Use these endpoints directly via curl, Python (requests), or browser (for GET).

Agent interaction.

curl -X POST https://atlas-e7ck.onrender.com/api/chat \
  -H "Content-Type: application/json" \
  -d '{"query": "Generate an image of a cat", "session_id": "test"}'

Python: import requests; res = requests.post('https://atlas-e7ck.onrender.com/api/chat', json={'query': 'hello'}).json()

Generate image.

curl "https://atlas-e7ck.onrender.com/api/generate/image?prompt=a cat"

POST: curl -X POST ... -d '{"prompt": "a cat"}'

Browser: https://atlas-e7ck.onrender.com/api/generate/image?prompt=a%20cat

Generate text.

curl "https://atlas-e7ck.onrender.com/api/generate/text?prompt=hello"

POST: Advanced params like temperature.

Generate audio.

curl "https://atlas-e7ck.onrender.com/api/generate/audio?prompt=hello&voice=alloy"

List models (text/image).

curl "https://atlas-e7ck.onrender.com/api/models/text"

Health check.

curl "https://atlas-e7ck.onrender.com/api/health"
Compatibility Notes
  • GET: Browser-friendly (e.g., ?prompt=...).
  • POST: JSON bodies for advanced (curl/Python).
  • Curl/Python: Examples above.
  • Swagger: Visit /api-docs for interactive (but using custom for professional look).
